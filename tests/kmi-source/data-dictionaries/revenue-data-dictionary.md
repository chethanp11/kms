Field: revenue_id stores the stable identifier for a revenue record.
Field: revenue_status stores the governance code that indicates active, pending, rejected, or modified state.
Field: source_ref stores the document path that produced the candidate.
Field: approval_date stores the date the knowledge manager approved the candidate.
Field: publisher stores the person or system that wrote the finalized wiki page.
Field: exception_notes stores the human-readable explanation for a temporary mismatch.
Rule: The source_ref must stay aligned with the archived raw document path.
