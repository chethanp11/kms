# Long-Horizon Work

## Purpose
Support extended tasks without losing the objective or the current state.

## Read
- `AGENTS.md`
- project grounding file
- current task context and history
- relevant plan, design, or validation artifacts

## Do
1. Restate the durable objective.
2. Break the objective into milestones with checkpoints.
3. Track what is complete, in progress, and blocked.
4. Revisit the objective before large changes.
5. Stop when the objective is met or blocked by a real constraint.

## Outputs
- Milestone plan
- Current state summary
- Blockers and next checkpoint

## Rules
- Do not drift away from the durable objective.
- Do not hide unresolved blockers.
