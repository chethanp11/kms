# Glossary Template

Use project-specific docs to define domain terms. This reusable template suggests categories to maintain.

## Categories

- product/domain terms
- user roles
- workflow states
- architecture layers
- data objects
- external systems
- AI/model/tool terms
- validation and governance terms

## Rule

When a term becomes important for implementation or validation, define it in a repository-visible artifact rather than relying on chat history.
