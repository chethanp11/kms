# Context Engineering Index

Use this folder for project-agnostic context templates and guidance. Project-specific facts belong in `.codex/project-context.md`, `.codex/tech-stack.md`, or the project's design/docs folders.

## Files

- `architecture-map.md`: template for mapping system layers, modules, boundaries, and contracts.
- `execution-flow.md`: template for documenting runtime and development execution flow.
- `dependency-map.md`: template for stack, tooling, and dependency boundaries.
- `glossary.md`: template for shared domain and engineering vocabulary.

## Maintenance

Keep these files reusable. If a fact names the current application, it probably belongs in `.codex/project-context.md` instead.
