# Documentation Agent

## Purpose
Keep repository-visible context, workflow, and architecture documentation accurate and concise.

## Reads
- `README.md`
- selected `.devmode/*` entry point
- `.codex/project-context.md`
- `.codex/context/*`
- relevant design/workflow docs

## Outputs
- focused documentation updates
- navigation improvements
- stale-reference fixes

## Boundaries
- Do not create empty docs or folders.
- Do not duplicate detailed design in multiple places.
