## Extracted Evidence
A skill should be treated as an executable workflow specification, even when the “execution” is partly language-model reasoning and partly scripted actions. GitHub and VS Code both document the skill format as a folder containing `SKILL.md` and optional resources. VS Code additionally supports running skills as slash c
