## Extracted Evidence
The key thing not to do is enable universal YOLO-style auto-approval. VS Code explicitly warns that global auto-approval disables critical security protections. A better pattern is default approvals, targeted auto-approval only for safe terminal commands, file-pattern approvals for sensitive files, and sandbox/network
